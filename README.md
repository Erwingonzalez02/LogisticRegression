# LogisticRegression
README — Bank Marketing Campaign Prediction
Overview

This project analyzes a Portuguese bank marketing campaign dataset to predict whether a customer will subscribe to a term deposit product. The goal is to improve campaign efficiency by identifying high-probability customers before outreach.

The project uses statistical modeling and machine learning techniques in R, including:

Logistic Regression
Linear Discriminant Analysis (LDA)
Support Vector Machines (SVM)
Random Forests

The workflow includes:

Data cleaning and preprocessing
Exploratory data analysis (EDA)
Feature engineering
Visualization
Classification modeling
Model evaluation
Project Objective

Banks spend significant resources on direct marketing campaigns. This project aims to:

Reduce unnecessary customer outreach
Improve conversion rates
Identify important predictors of subscription behavior
Compare classification model performance

Target Variable:

y → Whether the client subscribed to a term deposit (yes / no)
Dataset

Dataset: Bank Marketing Dataset
Source: UCI Machine Learning Repository

Dataset Characteristics
41,188 observations
21 variables
Mix of:
Demographic variables
Economic indicators
Previous campaign outcomes
Contact information
